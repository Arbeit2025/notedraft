# note記事ドラフトメーカー（notedraft）— note arbeit2025 専用

note アカウント「arbeit2025」（技術・個人開発系）のための統合ツールです。**記事案・下書きの生成**と、**公開済み記事の進捗管理（分析・監視）**を1つにまとめています。記事案と下書きは、外部 AI API を使わずテンプレートの組み立てで生成します。このアカウント専用に設計されています。

## 重要な注意

- **Studylog の未公開の発明要素・特許関連の秘密情報は入力しないでください。** 公開可能な範囲の話題だけを扱う前提のツールです。
- **下書きはテンプレート生成であり、そのまま公開するものではありません。** 公開前に必ず本人が推敲し、事実関係を確認してください。
- **記事の数値（スキ数・コメント数・ビュー数）は自動取得しません。** note の公式 API は使っておらず、数値は本人が note の画面を見て手入力する方式です。

## 機能

### 記事案・下書き生成

1. テーマ／キーワード、ジャンル（プリセット：個人開発・ツール制作／学習・研究メモ（公開可能な範囲）／Bot・自動化の運用記録／技術メモ・その他、自由入力も可）、トーン（カジュアル／丁寧／熱量高め）、長さ（短め／標準／長め）を選びます。
2. ハッシュタグ候補（個人開発、Python、Flask、GitHub、自動化、学習記録 など、この note 向けのプリセット）から付けたいものを選び、「記事案を3件作る」を押します。
3. 記事案（タイトル案×切り口の組み合わせ）が3件提示されます。選んだ案から下書きを作るか、タイトルを直接入力しても作れます。
4. 下書きは、タイトル・はじめに・見出し2〜3節（キーワードを織り込んだテンプレート段落）・まとめ・ハッシュタグ候補で組み立てられます。文字数表示とコピーボタンつきです。
5. 下書きは SQLite に保存でき、一覧・閲覧・削除、Markdown ファイルとしてのダウンロードができます。

### 下書きのパイプライン状態

- 保存した下書きには状態（**案／下書き／公開済み**）を持たせ、一覧から変更できます。
- 「公開済みにする」を押すと、その下書きのタイトル・ジャンルで公開記事として自動登録され（公開日は当日、URL は空欄）、下書きの状態が「公開済み」になります。URL はあとから記事の編集画面で入れられます。

### 公開記事の管理・数値の履歴

- 公開済み記事を登録します（タイトル、URL、公開日、ジャンル、スキ数、コメント数、ビュー数＝任意）。
- 記事一覧から「数値を更新」すると、現在の数値が上書きされると同時に、その日の確認履歴として残ります。一覧には前回確認時との差分（例：スキ +3）が表示されます。
- 記事の編集ページでは、タイトル・URL・公開日・ジャンルの修正と、数値履歴の確認ができます。削除も可能です（履歴ごと消えます）。

### 進捗ダッシュボード

- 総記事数、今月の投稿数、最終投稿日と今日までの経過日数、平均投稿間隔（記事2件以上のとき、先頭〜最終の期間÷間隔数）、ジャンル別本数、下書きの状態別件数を表示します。
- 計算はすべて登録済み記事・下書きのデータからのみ行います（外部からの自動取得はありません）。

## 設定

- **対象アカウント名**：SQLite に保持します（既定値「arbeit2025」）。画面下部の設定フォームから変更できます。
- **締めの定型文**（署名・締めの一文）：設定に保存すると、下書き生成時に自動で末尾に入ります（既定は空）。

DB のパスは環境変数 `NOTEDRAFT_DB` で変更できます。旧バージョンの DB（下書きに状態列がないもの）は、起動時の初期化で自動的に列が追加されます。

pip install -r requirements.txt
python app.py
# http://localhost:5000
```

python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 下書きはあくまでテンプレートの組み立てです。文章の質・独自性・事実の正確さは保証されません。推敲の土台としてのみ使ってください。
- note への自動投稿機能はありません。コピーまたはダウンロードして、本人が note に貼り付ける運用です。
- 記事の数値は手入力です。入力し忘れるとダッシュボードや差分は古いままになります。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
